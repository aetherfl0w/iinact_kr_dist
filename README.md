# iinact-kr-dist

Unauthorized redistribution of [FFXIV_ACT_Plugin](https://github.com/ravahn/FFXIV_ACT_Plugin) binaries, packaged as a Docker image to provide a stable download endpoint for [IINACT-KR](https://github.com/hareeen/IINACT-KR).

## What this repo does

- Hosts a pinned version of the pre-built `FFXIV_ACT_Plugin` zip from upstream
- Builds a minimal nginx container that serves `/version` and `/download` endpoints
